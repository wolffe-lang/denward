# Encryption v1

The selected profile is an ordinary binary age v1 file containing the complete safe-object pax archive, with native classical X25519 recipients. It is not a denward cryptographic wrapper. The published format at https://age-encryption.org/v1 and the immutable specification https://raw.githubusercontent.com/C2SP/C2SP/fc7f312aff098ed080f3dd5a3da4fd820be17a2e/age.md (SHA-256 b0a767b91a184c536e8a04002f7bba7521388fee3989f5891e23cc1aaa00232f) are normative for encryption bytes. No altered labels, new outer prefix/AAD/KDF, custom padding, plugin execution or cipher composition is allowed.

Use a fresh 16-byte file key, fresh 16-byte payload nonce and fresh 32-byte ephemeral scalar per recipient stanza. Standard age X25519 wrapping, original-header HMAC, HKDF labels and ChaCha20-Poly1305 chunk rules apply exactly. Payload plaintext chunks are at most 65536 bytes; the nonce is the standard 11-byte big-endian counter plus final flag. An exact nonempty multiple ends in a full final chunk, not an extra empty final chunk; empty input has one empty final tag. Reject missing final authentication and trailing bytes. Never release a chunk before its tag verifies.

Provision two independently generated native recovery identities on a trusted machine. Public recipients alone go onto PAX in authenticated configuration. Keep one private identity on the Mac and the second offline on separate USB media or paper. Two recipients provide OR recovery, not two-factor authentication. Retain the SSH retrieval credential and trusted host identity separately as well. Lost-all-identities means no recovery; there is no reset. Passphrase/scrypt mode is a later lane. No post-quantum or forward-secrecy claim is made for these retained classical archives.

Creation requires a qualified all-or-error cryptographic OS-random source. PAX must expose a fail-closed cryptographic-ready capability; existing reads that can silently use a TSC fallback do not qualify. Refuse `entropy_unqualified` before drawing. Under the pinned OS-random contract, provider failure after admission traps the process before any ciphertext is written; there is no recoverable `entropy_unavailable` outcome and never a plaintext fallback. Decryption is deterministic and is not blocked merely for lacking creation entropy. The receiver only stores/hashes ciphertext and needs neither a backup identity nor backup-encryption randomness.

Selected bounds: 256 MiB total process RSS, 1 MiB total raw header, at most 64 stanzas/identities attempted, 4096 bytes per argument line and checked signed-64-bit byte accounting. Unsupported armor/recipient/profile and over-budget inputs refuse by name. Keyless syntax checks never run an attacker-supplied KDF. Key input is a private descriptor or an identity-file path; no key bytes in argv, environment dumps, diagnostics or manifests. Scoped memory lifetime is not an erasure guarantee; wiping, dump policy and generated-code secret handling require independent qualification.

Per-object/logical digests stay inside encryption. The external receipt contains only opaque identity, selected profile, full ciphertext length/SHA-256 and publication state. Keep an expected ciphertext receipt on a separate trusted device/record. Age does not authenticate the source author: anybody knowing public recipients can encrypt a replacement. Adjacent replaceable receipts are not trust anchors.

SSH caches and temporary archive storage contain ciphertext only. No plaintext archive, manifest sidecar or sort/inventory spool is allowed. First-release inventory stays wholly in memory; its nonzero entry bound must be established from measured representation cost within 256 MiB before inspect/backup is enabled. The former million-entry proposal is withdrawn. Until that measurement exists, `inventory_budget_unqualified` is a blocker, not a guessed bound. Encrypted scratch metadata is a separately designed future option, not part of this release.

Restore pins a private complete ciphertext cache, verifies the expected ciphertext identity and the entire authenticated decrypted archive without target writes, then uses a second authenticated decrypt pass to apply the approved plan. Continue authenticating that pass and detect cache modification; a held descriptor alone does not make bytes immutable. Failure enters maintenance/recovery, never successful publication.

The first real backup is blocked on the selected entropy/primitive/codec gates, independent second-lane review, reference-age interoperability and an external key-recovery rehearsal. Each retained copy and each recovery identity is tested without the original source or an already-open vault session. Full real-backup restore rehearsal still precedes destructive installation. This scaffold emits no encrypted file and implements none of those successful paths.
